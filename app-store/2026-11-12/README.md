## 提交前剩余事项

1. 使用付费 Apple Developer Program 账号创建正式应用，确认名称、Bundle ID、版本号、价格及销售地区。
2. 大陆区：用 text/07 的询问稿向苹果确认纯离线相机是否适用备案豁免以及后台填写路径。若要求备案，再按实际主体和接入商办理；当前不能把豁免视为已确认。
3. 提供审核联系电话。邮箱和公开联系人已按用户确认填好。
4. 部署 website 目录到实际 HTTPS 站点，填写真实支持/隐私URL；若站点位于中国大陆，另核对网站备案要求。仅有本地HTML文件不满足公开URL要求。
5. 在应用内提供易访问的完整隐私政策入口；当前“关于”页只有概要，尚未接入本材料中的完整页面。
6. 核对正式发行包全部SDK的隐私清单、必需原因API、实际网络行为及App隐私标签。text/06中的“数据未收集”是按现有架构给出的候选，不能代替发行包审计。
7. 使用真实iPhone完成发布前验收，特别是多人美颜、Live、镜头/倍率、后台恢复、授权拒绝及系统相册保存删除。工程支持iPad，提交前也需完成对应设备验收。
8. 若界面或品牌又变化，重新生成截图；不要沿用已经与正式版不符的素材。支持页面上线时把隐私政策生效日期改为实际发布日。

## 网站部署说明

website 目录的全部文件放在同一公开目录，保持相对链接。支持URL指向 support.html，隐私政策URL指向 privacy.html。不得把本地路径或占位域名填进苹果后台。站点托管服务可能记录访问日志；选择托管商后，应在需要时补充网站访问的隐私说明，不能将网站和本地App的数据处理混为一谈。

本次没有发送支持邮件、购买域名、发布网站或提交苹果审核。文稿中没有编造备案号、审核电话或线上网址。
