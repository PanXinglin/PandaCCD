# 0.11.0：反向竖屏、美颜与相册入口

2026-11-02，build18。

## 方向修正

内屏使用普通系统横竖布局，不重新启用整页旋转补偿。此前预览方向根据窗口宽高判断，两个竖向均被归为portraitUp；现在展开屏保留portraitDown，交给官方CameraPreview处理180°方向，图标仍跟随系统界面。外屏竖屏锁定时继续固定预览方向，仅按钮随握持旋转，避免修复内屏时改变外屏策略。

## 一键美颜

- 默认关闭，取景页右下方美颜开关一键开启或关闭；设置中也可切换。状态跨启动保留，切换机型保留。
- 调一调中的自然美颜可调强度；编辑页也提供同一参数，照片编辑记录保留当次美颜值，重新编辑不会二次叠加。
- 用GLSL双边近邻采样平滑细碎纹理，以肤色范围与亮度遮罩限制作用区域，轻微提亮，保留明显边缘。未做人脸识别、瘦脸或五官形变；肤色遮罩可能影响颜色相近的背景，不能当作精确的人脸分割。
- 预览与导出共享同一shader；关闭时跳过额外采样，无逐帧CPU处理。不同光线、肤色和设备下的观感及帧率需真机评价，未宣称所有设备60fps。
- 旧照片/旧预设缺少beauty时按0恢复，不改变历史照片。

## 相册

按用户允许移除相册中的旧版关联提示区与按钮，不再每次显示迁移操作。新照片保存时仍自动记录系统相册关联ID，已关联照片的单张和批量联动删除保留，设置中的联动开关保留。未关联作品删除提示明确仅删除应用内文件，不再指向已移除的入口。

## 验证

63项测试通过，静态检查无问题。新增四个方向分类及外屏竖屏锁定回归、内屏portraitDown预览与正向图标共存、一键美颜开关、跨机型和预设记录、GPU肤色纹理平滑/非肤色及强边缘保留。拍后保存/重开编辑回归使用开启美颜的照片，确认参数保留、效果不重复叠加。相册批量与联动删除回归通过。

Android正常入口APK已构建，清单0.11.0/build18；无小米内屏真机连接，反向竖屏最终效果和美颜观感仍待真机确认；本轮没有iOS构建验证。
