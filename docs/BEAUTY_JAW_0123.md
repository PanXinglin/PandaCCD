# 0.12.3：下颌收窄与下巴保护

用户反馈0.12.2仍存在脸颊凹陷、下巴过尖。本次保留现有界面与调节范围，替换瘦脸位移计算。

原实现将四对下颌点和下巴点依次向嘴部拉动，多个局部影响区域会叠加，也会产生纵向位移。新实现根据下颌轮廓插值生成连续横向位移，每个像素只计算一次，不再向嘴部聚拢；嘴部以上、脸部中央及下巴末端保护，最高单侧位移限制为对应半脸宽的6%并乘以美颜和瘦脸强度。下巴长度不变，末端不再单独收尖。远处背景不改变，紧邻下颌的背景仍需平滑衔接。

算法继续由同一Dart/GLSL路径服务预览、照片及Live动态，不加入新SDK，不改变许可证配置。此前GPUPixel参考记录与许可证保留；本次连续横向位移并非直接调用其完整美颜引擎。

## 验证

- 单元/Widget测试72项通过。新增逐像素检查：嘴部以上和下巴末端保持原图；最大强度不产生过量收窄，下颌逐行保持连续，无脸时不改变画面。
- Android36模拟器原生ML Kit与GLES人像渲染通过，已审阅0/25/100强度输出；见[QA记录](qa/beauty-face-0123.txt)。静态分析无问题。
- 本轮重点修复正面脸型凹陷和尖下巴，不声称覆盖所有侧脸、遮挡与快速转头情况。尚无用户真机验收；iOS未进行完整Xcode构建。
