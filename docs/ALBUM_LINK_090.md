# 0.9.0 相册联动与交互修正

## 使用方式

- 快门声改为一段实际相机快门录音，替代0.8.0合成音，原有声音开关和静音策略保留。声音来源见THIRD_PARTY.md。
- 风格栏所在浮层整体按28dp圆角抗锯齿裁切。滑动后处于左边缘的卡片、文字和点击水波纹都受约束，滚动位置和预设状态保持。
- 相册删除联动默认开启，可以在设置关闭。新成片写入系统相册时记录系统资源ID，反复存入不会重复复制。权限被拒仍保存本地成片。
- 第一次进入作品库，点“授权并关联”，允许完整照片访问；已有完整授权时按钮显示“关联旧照片”。只授权部分照片时不会自动移除本地作品。
- 旧作品只有在系统副本的文件名及PNG内容完全一致时才关联，照片详情显示关联状态。之前已从系统删掉、改过文件名/内容或被重新压缩的旧照片无法可靠追溯，保留本地；不伪称已同步。
- 应用内删除已关联照片，会明确提示同时删除系统照片及本地成片、原图和编辑记录。系统需要确认时尊重其确认结果，取消则保留本地作品。未关联或关闭联动时明确提示仅删除本地。
- 系统相册删除后，回到作品库/照片详情或点刷新会核对已关联资源并清理本地记录。相机页不持续扫描系统相册，不影响连续拍摄。

## 边界

这不是浏览整个系统相册的替代品，只管理熊猫CCD成片的对应资源，不删除系统中其他照片。完整照片读取权限仅在用户点授权或确认需要的删除操作时申请，不在拍照时额外请求。Android13+只读取图片，Android14+支持部分授权但不据此判定删除；iOS保留最小写入权限，读取需单独确认。

外部删除按系统资源是否仍在活动相册判定；不同厂商回收站、云相册、多设备同步和恢复行为需真机复核。应用中的原图与编辑记录随联动删除一起清理；从系统回收站恢复不会凭空重建已删除的应用原图和参数。旧版已删除的系统副本无法追溯。

## 验证方法

单元/界面回归覆盖重复导出、资源关联持久化、双向删除、取消系统删除、部分授权/撤权/未知状态、多个副本、关闭联动、旧记录无匹配、并发保存与刷新、风格栏圆角像素和原有滚动状态稳定性。

Android设备测试：运行`flutter test integration_test/album_link_test.dart -d <测试模拟器> --enable-impeller`，把输出写入日志；另运行`python3 tool/drive_album_link_test.py <adb路径> <日志路径>`。只可使用可丢弃测试设备：该驱动授予照片访问，并删除测试打印出的单个新建媒体资源，验证外部删除后同步；不操作其他照片。iOS未编译/真机验证。
