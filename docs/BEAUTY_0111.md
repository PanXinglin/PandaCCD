# 0.11.1：增强磨皮，避免被CCD颗粒抵消

2026-11-02，build19。

用户确认0.11.0内屏反向竖屏和旧相册关联入口问题已修好。本次不改方向与相册逻辑，仅优化美颜。

## 调研依据

以下是产品公开功能和推荐组合，不能据此推断所有中国女性的统一偏好，也不直接照抄其他SDK的数值：

- [美图秀秀官方相机说明](https://www.meituxiuxiu.com/zh-Hans/academy/camera)：美颜包含肤质、磨皮、立体、去暗沉等，肤质处理不只是提高曝光。
- [美图影像实验室](https://mtlab.meitu.com/news/2)：说明磨皮与细节保留的取舍，目标是皮肤平滑、五官结构清晰。
- [腾讯美颜场景推荐](https://cloud.tencent.com.cn/document/practice/616/66340)：将磨皮、美白、清晰度、五官塑形分别配置；一键效果是组合，不是单一亮度值。
- [GPUPixel官方美颜文档](https://gpupixel.pixpark.net/call/beauty_effects)：美肤与人脸变形是独立功能；瘦脸、大眼、妆容需要额外的人脸特征定位。本次未引入其代码或原生库，仅参考功能组织思路。
- 搜到的[抖音轻颜调参内容](https://www.douyin.com/shipin/7262936621899843640)提到磨皮、清晰度、美白组合，仅作个别内容参考，不作为代表性用户调查。小红书未取得足够可靠的原始样本，不宣称完成其用户调研。

## 修改

旧版仅8个近邻、范围权重偏紧，实际磨皮较轻；效果之后又叠加CCD颗粒与色彩断层，削弱了皮肤平滑观感。

新版GLSL采用24个近邻的扩大范围边缘感知平滑，采样半径按图像短边归一化；由局部肤色共同构成遮罩，让小块偏红/偏暗瑕疵也能参与平滑。适度匀肤、暗部提亮和减弱偏黄，保护强边缘及高光。皮肤遮罩内降低CCD噪点和断层，其他区域继续保留复古效果。开关与强度仍共用同一参数，默认关闭，开启强度仍为0.55，未通过单纯拉大默认数值制造差异。

当前是肤色区域的美肤，不包含瘦脸、大眼、祛眼袋或自动上妆。没有人脸关键点和精确分割，肤色相近背景可能受影响，较大斑点不能保证消除。没有云端上传，仍是Flutter/Dart/GLSL跨平台处理。

照片编辑记录保留原参数格式；历史成片PNG不变。重新渲染旧编辑记录时若美颜非0，使用新版算法，观感会有变化。

## 验证

64项测试通过，静态检查无问题。新增默认0.55强度下CCD皮肤颗粒减弱、非肤色颗粒保留回归；其余覆盖预览开关、保存再编辑和四向窗口等。

用[Pexels Roberto Hund人像](https://www.pexels.com/photo/serious-asian-woman-looking-at-camera-5317540/)进行真实shader离线对比：关闭、0.55、1.0，分别在预设强度0与G12默认风格下查看额头/脸颊、五官及头发。观察到皮肤纹理平滑更明显，眼睛/睫毛/头发轮廓保留。仅代表该测试图观感，不代表所有肤色、光线与设备效果。照片不打包进应用，未调用AI生成图作为效果证据。手动复现工具：`tool/beauty_portrait_qa.dart`，通过PANDA_BEAUTY_PHOTO指向本地照片。

关闭美颜时跳过额外采样；开启后额外采样从8增至24。仍使用GPU，没有逐帧CPU处理；本轮无连接真机，未测得设备实时帧率，不宣称所有机型60fps。Android正常入口APK构建成功并核对0.11.1/build19；本轮未进行iOS构建。
