# 0.10.5：内屏恢复普通横竖布局

2026-11-02，build17。

用户提供5.39秒真机录屏，连续短帧可见转向中整页系统动画，以及转向停稳后工具栏和文字仍侧着、返回竖向再次翻转。此前CameraViewport反向旋转整个场景依赖相机方向事件，未能可靠匹配该内屏的系统窗口坐标。

按用户已确认的回退优先级处理：

- CameraViewport保留实际窗口宽高与系统边距，取消整个场景的RotatedBox补偿。横向内屏按原有布局使用右侧操作区，竖向使用底部操作区。
- 内屏按钮跟随系统界面，不使用传感器或场景额外旋转；自然横向显示上报portraitDown时也不能把图标倒置。
- 内屏尺寸变化不再覆盖350ms旧取景快照，避免旧方向画面在新布局中短暂出现。
- 外屏的竖屏偏好和握持按钮旋转不变。保留展开屏解除方向锁、生命周期处理、本地官方插件空帧修正和已授权的SEAMLESS窗口配置。
- 布局变化不主动重开相机，滤镜仍为Dart/GLSL。

本版目标是恢复内屏正常显示和操作，允许系统转屏过渡，不宣称彻底消除真机闪动。验收时需确认内屏铺满、文字图标直立、预览不压扁，以及折叠回外屏后按钮方向正常。

验证记录见ACCEPTANCE.md。新版本没有连接小米真机；本地模拟器系统镜像及配置被临时目录清理，本轮不能执行原生内屏集成测试，不能以单元测试代替真机验收。
