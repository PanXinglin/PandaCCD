# 0.10.1：保持原有设计，改善旋转连续性

2026-10-29，build13。用户最终撤回C方向，明确保留0.10.0原有设计；本版没有采用四方向样机。

## 修改

- 手机与折叠外屏保持取景窗口稳定；稳定握持后只旋转工具图标/画幅文字，快门与工具点击位置不变。
- 拍照方向通过官方相机接口单独设置，拍完释放方向锁定，避免固定窗口导致横拍保存成竖图。
- 大窗口与折叠内屏保留系统窗口响应布局。Android大屏可能忽略方向锁，不能依赖型号或强制方向。
- 相机插件两种Android预览路径原先在等待异步方向查询时返回空白；现在等待期间继续显示已挂载的纹理。
- 转向、打开镜头和拍照期间的暂时卡顿不计入实时预览降档窗口，避免将转场耗时误判为滤镜持续性能不足。

## 官方插件的Dart补丁

本地保留官方camera 0.12.1与camera_android_camerax 0.7.6，许可证完整保留。
仅改三份Dart展示代码，原生目录无改动；滤镜仍为Dart/GLSL。
详见 `third_party/CAMERA_PREVIEW_PATCH.md`。这些本地依赖需要随工程一起分发。

## 验证

- 静态检查无问题，55项自动测试通过。
- 两种Android预览后端：让系统方向查询连续等待六帧，确认纹理每帧都存在且未重新挂载。
- 模拟器实际摄像头+传感器：竖→左横→右横→竖；相机、预览、纹理保持同一对象，快门位置与窗口尺寸保持不变。
- 每个方向拍照：左横1280×720、右横1280×720、竖拍720×1280。使用真实CameraOrientation服务，未用disabled替代。
- 用main.dart正常入口重新构建Android debug包；清单版本0.10.1/build13。

## 尚待确认

模拟器通过不能证明所有真机不闪。小米/三星折叠内外屏连续切换、自然方向不同的内屏、前置镜头、iOS原生构建和真机预览仍待实测。没有针对尚未发布设备作兼容性承诺。
