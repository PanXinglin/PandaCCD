# 熊猫 CCD 0.14.1

- Live 需要重配取景时，保留原来的模糊过渡。根据当前纹理对应的相机帧和曝光状态，等取景连续出帧后再淡出。两端平台桥只提供帧计数和曝光状态，核心滤镜仍为 Dart / GLSL；不截图轮询。遇到不报告状态的设备有等待上限。
- Android 后摄的三种闪光灯设置沿用同一个 30fps 会话，避免开关时为了改变帧率重建相机。前摄和 iOS 的帧率策略不变。
- 手势调倍率时，数字立即跟随输入。CameraX 只继续发送最新目标，允许新目标替换较早的相机请求。选中底在档位间短距离滑动，数字用等宽特性；开启系统减弱动态效果时，档位底直接更新。
- 连续内屏的折痕不再让相机布局避让到半边；真实遮挡铰链和开孔仍按系统区域避让。这一改动不触发相机重建。
- 页面标题改为设置。图标保留原轮廓、暖象牙色外底，镜头外圈增加一层香槟铜色。

验证：89 项自动测试与 Flutter 静态检查通过。Android 36 模拟器最终包的 Live 录屏中，取景区 97 帧未出现黑帧，快门亮度稳定；首次 Live 开启的日志确认收到连续三帧稳定曝光。安卓实体闪光、实际折叠半开行为以及 iPhone Live 淡出观感需各自真机复测。iPhone 14 Pro 已核对安装 0.14.1（40）。
